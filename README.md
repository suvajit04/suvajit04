# 🎮 Suvajit's Gaming UI Portfolio

A high-end, interactive gaming-style portfolio website showcasing my projects and skills. Built with modern web technologies and featuring a stunning dark theme with neon accents.

## 🌟 Features

### 🎨 Visual Design
- **Gaming UI Aesthetic**: Modern dark theme with neon cyan, magenta, and yellow accents
- **Glitch Effects**: Animated glitch text effects on the hero title
- **Parallax Scrolling**: Dynamic star field background with parallax effect
- **Smooth Animations**: Fade-in, slide-in, and hover animations throughout
- **Responsive Design**: Fully responsive on all devices (desktop, tablet, mobile)

## 🚀 How to Use

1. **View Online**
   - Open `index.html` in your web browser
   - Or deploy to GitHub Pages, Netlify, Vercel, etc.

2. **Customize**
   - Edit project information in HTML
   - Modify color scheme in CSS variables
   - Update social links in contact section
   - Add your GitHub username to API calls

3. **Deploy to GitHub Pages**
   ```bash
   # Push to your suvajit04 username repository
   git push origin portfolio-gaming-ui
   # Enable GitHub Pages in repository settings
   # Point to the root of the portfolio-gaming-ui branch
   ```

## 📝 Customization Guide

### Change Colors
Edit the CSS variables in `styles.css`:
```css
:root {
  --primary-color: #00d4ff;
  --secondary-color: #ff006e;
  /* ... change colors here ... */
}
```

### Add More Projects
1. Copy a project card HTML block
2. Update the text, icon, and tech stack
3. Link to your GitHub repository
4. Add data-filter attribute for filtering (optional)

### Update Contact Links
Replace placeholder links in the contact section with your actual:
- GitHub profile
- Email address
- LinkedIn profile
- Twitter/X profile
